Every project below started as a real operational problem — not a portfolio exercise. All were built and deployed in active manufacturing environments.

01 / 05
Material Availability & Runability System
Excel · VBA · Power Query · BOM Analysis

Production planners were manually exporting Fishbowl data, reformatting it, and copying it into a series of disconnected spreadsheets to answer a simple question: can we run this order? The process took hours and was error-prone. Built a fully automated workbook that accepts a raw Fishbowl on-hand export, explodes it against open sales order BOMs, and produces a complete runability picture — cook ingredients, packaging components, critical shortages, and a sales-order-level "ready to run" status — with a single macro click.

Problem

Hours of manual export, reformatting, and cross-referencing to answer basic production readiness questions

Solution

Single-click automation: raw Fishbowl export in, complete runability analysis out — cook ingredients, packaging, shortages, and order status

Excel / VBA Power Query BOM explosion Fishbowl ERP Inventory analysis Production deployed
Impact: Eliminated multi-hour manual process. Planner runs one macro and has a complete availability picture in under 60 seconds.
02 / 05
Material Availability Power BI Dashboard
Power BI · OneDrive · SharePoint · Auto-refresh

The Excel workbook solved the planner's problem but didn't solve the floor's problem — production staff, QA, and management were still asking "can we run this?" because they had no access to the workbook. Extended the system into a Power BI dashboard connected live to the OneDrive-hosted workbook, embedded directly in the team's SharePoint page. The dashboard auto-refreshes on a schedule; anyone on the team opens a browser tab and sees current availability status with zero friction, zero files, zero training required.

Problem

Operational staff couldn't access availability data without finding the file, opening it, and running the macro themselves

Solution

Live Power BI dashboard on SharePoint — auto-refreshes from OneDrive source, visible to entire team with no action required

Power BI Power Query (M) OneDrive SharePoint Scheduled refresh Production deployed
Impact: Self-service availability data for the entire operations team. Reduced planner interruptions for routine status questions.

04 / 05
Kitchen Yield & Scrap Rate Dashboard
HTML · JavaScript · Manufacturing Analytics

Actual gummy yield per batch was tracked inconsistently across production runs, making it difficult to identify variance by SKU, kitchen, or operator. Built an interactive analytics dashboard for tracking actual vs. expected yield across 200+ active SKUs, with searchable SKU selection, batch-level input, and variance visualization. Informed both production decisions and customer-facing distillate order calculations.

Problem

No systematic yield tracking — scrap rates calculated manually and inconsistently, with no way to identify patterns by SKU or run

Solution

Interactive dashboard with full SKU library (200+ items), batch-level tracking, and actual vs. expected variance analysis

HTML/CSS/JS Manufacturing analytics Yield analysis 200+ SKUs Production deployed
Impact: Identified yield variance patterns by SKU and run. Enabled more accurate customer-facing distillate order calculations.
05 / 05
Operational Platform Architecture
Systems Design · Supabase · Fishbowl/MySQL · CMMS · LIMS

Designed the architecture for a unified operational data platform to replace a fragmented collection of spreadsheets and manual processes — covering CMMS (maintenance), LIMS (lab/QA), HSE dashboards, training tracking, and supplier scorecards. Designed around a Supabase/Postgres core with nightly Fishbowl MySQL sync, Microsoft 365 authentication, and React/Blazor front end. Key design principle: Fishbowl is the system of record and is never modified — the platform is an analytical and quality layer alongside it.

Problem

Five operational systems needed (CMMS, LIMS, HSE, training, supplier scorecards) with no systems engineer, no IT support, and no budget for enterprise software

Solution

Unified platform architecture on Supabase ($0–25/mo), with Fishbowl sync script, M365 auth, and modular front end — deployable incrementally without IT involvement

Systems architecture Supabase / Postgres Fishbowl / MySQL CMMS LIMS M365 / Azure AD
Impact: Roadmap for replacing $50k+/year enterprise system spend with a maintainable, self-hosted platform built on existing infrastructure.
